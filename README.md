# 大模型学习之旅

一个单文件交互式课程页，面向希望从数学直觉一路学到 LLM 工程实践的学习者。课程从向量、矩阵、导数、概率开始，逐步进入神经网络、Transformer、训练对齐、自动微分、LoRA、优化器、分布式训练、硬件加速，以及 RoPE、FlashAttention、ZeRO、量化、DPO 等前沿主题。

## 项目特点

- 26 个课程章节，覆盖数学基础、机器学习、深度学习、LLM 架构与生产实践。
- 单文件页面：核心课程、样式和交互都在 `index.html` 中。
- 课程采用“费曼式理解 + 数学原理 + 代码锚点 + 动手练习”的组织方式。
- 内置 canvas 互动、滑块实验、小测验、填空式代码练习和费曼检验。
- 使用 Playwright 做页面回归校验，确保章节切换、练习渲染和高级章节内容正常。

## 快速开始

直接用浏览器打开：

```bash
open index.html
```

也可以用任意静态服务器启动，例如：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 安装依赖

```bash
npm install
```

当前测试脚本通过 Playwright 启动本机 Google Chrome，因此需要系统中已安装 Chrome。

## 运行校验

```bash
npm test
```

测试会执行 `scripts/check-page.js`，主要检查：

- 页面能正常加载。
- 导航章节数量为 26。
- 第 21-25 章可以正常切换。
- 高级章节的“代码落地任务”存在。
- 第 21-25 章动手练习可以被自动填写并验证通过。
- 页面没有捕获到运行时错误。

## 维护约定

- 优先保持当前设计语言，不轻易改动全局 CSS、导航结构和 canvas 交互逻辑。
- 新增数学内容尽量沿用现有 `sec`、`fey`、`ana`、`math`、`kp` 等结构。
- 新增练习优先使用已有 `ex()` 组件。
- 修改 `index.html` 后建议运行：

```bash
npm test
```
